# Nucleolar Stress Score

This repository contains the analysis scripts used to construct, validate, and apply a nucleolar stress score (NuS) across transcriptomic, proteomic, single-cell, spatial transcriptomic, TCGA/GTEx, and perturbation-screening datasets.

NuS is designed to quantify transcriptional programs associated with nucleolar stress. In most scripts, the score is calculated from paired upregulated and downregulated NuStress gene sets using GSVA or ssGSEA:

```text
NuS = enrichment score(NuStress_UP) - enrichment score(NuStress_DOWN)
```

The repository is organized as executable analysis scripts rather than an R package. Most scripts use absolute paths from the original analysis environment; update those paths before running the code locally.

## Repository Structure

```text
01_Dataset_analyse/
  Dataset-level preprocessing and differential expression analyses for public GEO cohorts.

02_Geneset_establish_analyse/
  Scripts used to construct and refine the NuStress gene sets, including literature genes,
  GEO-derived signatures, KEGG/pathway comparisons, and DepMap-related analyses.

03_Data_validation/
  Validation analyses across independent GEO datasets using NuStress scores.

04_Proteomics.R
  Proteomics-based ssGSEA analysis of NuStress and RiboSis gene sets.

05_scRNA-seq.R
  Single-cell RNA-seq analysis, NuStress/RiboSis scoring, epithelial-cell quadrant analysis,
  differential expression, and pathway enrichment.

06_Spatial_transcriptome/
  Spatial transcriptomics scripts for colon and liver samples, manual annotation,
  NuStress/RiboSis scoring, visualization, and downstream comparisons.

07_TCGA/
  TCGA/GTEx pan-cancer workflow:
    01_download_tcga_gtex_raw_data.R
    02_preprocess_tcga_gtex_data.R
    03_score_nustress_ribosis_ssgsea.R
    04_pan_cancer_tumor_normal_analysis.R
    05_tp53_association_analysis.R
    06_tp53_stratified_de_enrichment_analysis.R
    07_stratified_survival_analysis.R
    08_crc_cms_analysis_CMScaller.R
    09_crc_cms_analysis_CMSclassifier.R

08_CAMP.R
  CMap/LINCS perturbation analysis for drug-level NuStress scoring and comparison with
  normality scores.
```

## Data

Large raw and processed datasets are not included in this repository. The scripts expect external data from sources such as GEO, TCGA/GTEx via UCSC Xena, CMap/LINCS, and local intermediate RDS/Rdata files generated by earlier steps.

Before running the scripts:

1. Download the required source datasets.
2. Update absolute paths such as `base_dir`, `workdir`, `nus_rdata`, and `ribosis_rdata`.
3. Run scripts in the numbered order where applicable.

## Basic Usage

This repository is meant to reproduce analysis workflows rather than provide a single command-line tool. A typical workflow is:

1. Build or load the final NuStress gene sets from `02_Geneset_establish_analyse/`.
2. Score datasets with `GSVA::gsva()` or `GSVA::ssgseaParam()`.
3. Compare NuS across biological conditions, tumor/normal states, cell types, or perturbations.
4. Use downstream scripts for visualization, survival analysis, TP53-stratified analysis, CMS analysis, or pathway enrichment.

Example score definition:

```r
NuS_score <- ssgsea_res["NuStress_UP", ] - ssgsea_res["NuStress_DOWN", ]
```
